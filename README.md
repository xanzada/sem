# SEM — автоматический оператор заявок

SEM — это worker-бот на Playwright с веб-панелью управления: обрабатывает заявки на сайте
(находит → открывает → проверяет статус → принимает → подтверждает результат) и **никогда не теряет
рабочее состояние** из-за проверок безопасности, истёкшей сессии или перезапуска сервера.

Ключевой принцип: `ПРОВЕРКА БЕЗОПАСНОСТИ ≠ ОТКАЗ БОТА` — это временное состояние workflow.

## Возможности

- 🖥 Веб-панель (RU, dark theme, mobile-first): статус в реальном времени, живая лента действий,
  аналитика (сколько заявок принято и с какой скоростью), настройки, журнал инцидентов, VNC.
- ⏯ Управление: Старт / Пауза / Стоп, ползунок скорости бота (×0.25…×3).
- 🔐 Автоматический вход при потере сессии; если не получилось — уведомление в Telegram и ожидание оператора.
- 🛡 При появлении проверки безопасности бот НЕ кликает ничего, НЕ перезагружает страницу и НЕ создаёт
  новый браузер — он сохраняет checkpoint и ждёт, пока сайт сам пропустит его, затем перепроверяет состояние.
- ♻️ Защита от дублей: перед каждым критическим действием пишется intent в базу (action ledger).
  После любого прерывания SEM сначала читает фактический статус заявки на сайте и никогда
  не повторяет уже выполненное действие.
- 💾 Checkpoints в SQLite: workflow_id, application_id, шаг, URL, скриншот. Рестарт контейнера/VPS
  возобновляет работу с последней безопасной точки.
- ❤️ Keep-alive: лёгкая активность без навигации, чтобы сайт не разлогинил сессию при простое.

## Быстрый старт (локально)

```bash
npm install
npm run build
HEADLESS=true PORT=8080 npm start
# панель: http://localhost:8080
```

По умолчанию включён демо-режим (`simulation`) — SEM имитирует обработку заявок, включая редкие
«проверки безопасности» и «потери сессии», чтобы показать все состояния интерфейса.

## Docker

```bash
docker compose up -d --build
```

- Панель: порт `8080`
- noVNC: порт `6080` (только localhost на хосте; наружу — через SSH-туннель или reverse-proxy с авторизацией)
- Профиль браузера и база данных: папка `./data` (volume) — переживают перезапуск контейнера.

## Dokploy

1. Создайте приложение из GitHub-репозитория (Dockerfile в корне).
2. Порт: `8080`.
3. Environment variables:
   - `NOVNC_PUBLIC_URL` — публичный https-адрес noVNC (например, через второй сервис/domain), для вкладки VNC;
   - `TZ=Asia/Almaty`.
4. Логин/пароль сайта вводятся в панели «Настройки» (хранятся локально в SQLite на вашем VPS,
   в git и логи не попадают).

## Настройки (панель → Настройки)

| Параметр | Описание |
|---|---|
| Режим | Демо или Боевой |
| Адрес сайта / логин / пароль | Куда входить и кем |
| Селекторы (JSON) | CSS-селекторы элементов сайта: строка списка, кнопка «Принять», маркеры статусов |
| Скорость × | Множитель задержек между действиями |
| Keep-alive, сек | Интервал поддержания активности сессии |
| Таймаут проверки безопасности | Сколько ждать авто-разрешения до SAFE_STOP |
| Telegram token/chat | Уведомления о 🔐🟠🛡 событиях |

## Состояния бота

| Состояние | Значение |
|---|---|
| 🟢 Работает | Нормальная обработка заявок |
| 🟡 Пауза | Остановлено оператором (кнопка ⏸) |
| 🔐 Требуется вход | Сессия истекла: идёт автологин либо ждёт оператора |
| 🛡 Ожидание проверки | Сайт показал security challenge — ждём его завершения |
| 🟠 Требуется внимание | Нестандартная ситуация, нужен оператор (VNC/журнал) |
| 🔴 Ошибка | Сбой цикла, будет повтор автоматически |
| ⏸ Остановлен | Полностью остановлен, checkpoint сохранён |

## Архитектура

```
src/
  index.ts       bootstrap, graceful shutdown
  server.ts      Fastify REST API + WebSocket live feed + static UI
  engine.ts      конечный автомат состояний, основной цикл OBSERVE→CLASSIFY→ACT→VERIFY→CHECKPOINT
  workflow.ts    драйверы: DemoDriver (симуляция) и LiveHttpDriver (боевой, по селекторам)
  classifier.ts  классификация страницы: NORMAL / AUTH / SECURITY / UNEXPECTED
  browser.ts     один постоянный Chromium-профиль (launchPersistentContext)
  ledger.ts      action intents — защита от повторных нажатий
  checkpoint.ts  точки восстановления workflow
  analytics.ts   статистика принятых заявок
  telegram.ts    уведомления
public/          панель (vanilla JS, тёмная тема, RU, mobile-first)
```
